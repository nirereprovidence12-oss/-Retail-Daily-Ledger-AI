### 🎯 Goal
Zero backend. Zero cost. Works when network fails in Lusaka markets.

### ✨ What it is now (Clean Build)
- **100% PWA** - installable, works offline, no internet needed
- **Serverless** - only Firebase Hosting, no Cloud Functions, no server to pay
- **Lightweight** - `public/` = only 2 files: `index.html` + `fixes.js` (<200KB)
- **LocalStorage only** - all sales, inventory, suppliers saved in browser
- **POS + Inventory** - barcode, quick -1/-5 deductions, FIFO ready
- **Guest Mode + Real Sign Out** - instant exit, no fake loading
- **Voice Input** - `at` → `@` auto-fix
